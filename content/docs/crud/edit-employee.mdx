Edit adalah proses membaca data lama, menampilkan form dengan nilai awal, lalu menyimpan perubahan.

## Route Edit

Route:

```text
/employees/[id]/edit
```

File:

```text
app/employees/[id]/edit/page.tsx
```

## Server Action Update

Server Action bisa menerima argumen tambahan dengan `bind`.

```ts filename="app/employees/actions.ts"
"use server";

import { revalidatePath } from "next/cache";
import { redirect } from "next/navigation";
import { parseEmployeeInput } from "./validation";

export async function updateEmployee(
  id: string,
  formData: FormData,
) {
  const input = parseEmployeeInput(formData);

  await saveEmployeeUpdate(id, input);

  revalidatePath("/employees");
  revalidatePath(`/employees/${id}`);
  redirect(`/employees/${id}`);
}
```

`id` berasal dari route params, sedangkan `formData` berasal dari submit form.

## Halaman Edit

```tsx filename="app/employees/[id]/edit/page.tsx"
import Link from "next/link";
import { notFound } from "next/navigation";
import { updateEmployee } from "../../actions";
import { getEmployeeById } from "../../data";

export default async function EditEmployeePage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const employee = await getEmployeeById(id);

  if (!employee) {
    notFound();
  }

  const updateEmployeeById = updateEmployee.bind(null, employee.id);

  return (
    <main>
      <Link href={`/employees/${employee.id}`}>Back to detail</Link>
      <h1>Edit employee</h1>

      <form action={updateEmployeeById}>
        <label htmlFor="name">Name</label>
        <input id="name" name="name" defaultValue={employee.name} required />

        <label htmlFor="email">Email</label>
        <input
          id="email"
          name="email"
          type="email"
          defaultValue={employee.email}
          required
        />

        <label htmlFor="position">Position</label>
        <input
          id="position"
          name="position"
          defaultValue={employee.position}
          required
        />

        <label htmlFor="department">Department</label>
        <input
          id="department"
          name="department"
          defaultValue={employee.department}
          required
        />

        <button type="submit">Save changes</button>
      </form>
    </main>
  );
}
```

Gunakan `defaultValue` untuk input form yang tidak dikontrol oleh state React.

## Kenapa Tidak useState?

Untuk form sederhana, uncontrolled input dengan `defaultValue` sudah cukup. Ini mengurangi JavaScript client karena halaman edit tetap bisa menjadi Server Component.

Gunakan Client Component jika form membutuhkan interaksi kompleks seperti preview real-time, field dinamis, atau validasi client yang detail.

## Ringkasan

Edit flow membaca data berdasarkan `id`, menampilkan form dengan nilai awal, memanggil Server Action update, melakukan revalidation, lalu redirect ke halaman detail.
