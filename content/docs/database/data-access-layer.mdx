---
title: Data Access Layer
description: Membungkus query database agar akses data lebih aman dan rapi.
---

Data Access Layer atau DAL adalah tempat khusus untuk membaca dan menulis data. Di Next.js, DAL membantu menjaga database client dan secret tetap berada di server.

DAL juga menjadi tempat yang baik untuk authorization dan pembentukan DTO.

## Struktur Folder

Contoh struktur:

```text
data/
+-- employees.ts
lib/
+-- db.ts
```

`lib/db.ts` berisi database client. `data/employees.ts` berisi function untuk kebutuhan domain employee.

## Server Only

Tambahkan `import "server-only"` pada module DAL.

```ts filename="data/employees.ts"
import "server-only";

import { db } from "@/lib/db";
```

Ini membantu mencegah module database tidak sengaja diimpor ke Client Component.

## DTO

DTO atau Data Transfer Object adalah bentuk data yang aman dikirim ke UI.

```ts filename="data/employees.ts"
export type EmployeeDTO = {
  id: string;
  name: string;
  email: string;
  position: string;
  department: string;
};
```

Jangan selalu mengirim raw database record. Pilih field yang memang diperlukan UI.

## Function Read

```ts filename="data/employees.ts"
export async function getEmployees(): Promise<EmployeeDTO[]> {
  const employees = await db.employee.findMany({
    orderBy: {
      createdAt: "desc",
    },
    select: {
      id: true,
      name: true,
      email: true,
      position: true,
      department: true,
    },
  });

  return employees;
}
```

## Function Detail

```ts filename="data/employees.ts"
export async function getEmployeeById(
  id: string,
): Promise<EmployeeDTO | null> {
  const employee = await db.employee.findUnique({
    where: { id },
    select: {
      id: true,
      name: true,
      email: true,
      position: true,
      department: true,
    },
  });

  return employee;
}
```

## Function Mutation

Mutation juga bisa diletakkan di DAL agar Server Action tetap tipis.

```ts filename="data/employees.ts"
export type EmployeeInput = {
  name: string;
  email: string;
  position: string;
  department: string;
};

export async function createEmployee(input: EmployeeInput) {
  await db.employee.create({
    data: input,
  });
}
```

## Ringkasan

Gunakan Data Access Layer untuk membungkus query, membatasi data yang dikirim ke UI, dan menjaga aturan akses data tetap konsisten.
