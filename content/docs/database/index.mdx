<Callout type="info" title="Fokus utama bab ini">
Bab ini membahas integrasi database di Next.js: ORM, environment variable, schema, migration, Data Access Layer, query dari Server Component, mutation dari Server Action, relasi, security, dan performa.
</Callout>

![Diagram alur database di Next.js](/diagrams/database-flow.svg)

Bab ini membahas cara menghubungkan aplikasi dengan database agar data tidak hanya hidup di memory atau file sementara.

Pada bab CRUD sebelumnya, data layer masih bersifat sementara. Di bab ini, data layer tersebut mulai diarahkan ke database sungguhan dengan ORM seperti Prisma atau Drizzle.

Fokus utamanya bukan memilih satu ORM saja, tetapi memahami pola integrasi database di Next.js App Router: tempat menyimpan koneksi, cara membaca data dari Server Component, cara melakukan mutation dari Server Action, serta cara menjaga data private tetap berada di server.

## 🎯 Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat membuat model data, menjalankan query, dan menghubungkan CRUD ke database.

## 🧠 Mental Model

```text
Database menyimpan data
ORM mendeskripsikan schema
Migration mengubah struktur tabel
Data Access Layer membungkus query
Server Component membaca data
Server Action mengubah data
Revalidation menyegarkan UI
```
