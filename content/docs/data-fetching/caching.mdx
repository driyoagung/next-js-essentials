Caching adalah teknik menyimpan hasil kerja agar request berikutnya tidak perlu menghitung atau mengambil data dari awal.

Pada Next.js, caching bisa terjadi di beberapa level: response `fetch`, hasil fungsi async dengan Cache Components, output halaman, dan cache browser saat navigasi.

## Fetch Cache

Untuk request yang datanya relatif stabil, kamu bisa memakai `force-cache`.

```ts
async function getCategories() {
  const response = await fetch("https://example.com/api/categories", {
    cache: "force-cache",
  });

  return response.json();
}
```

Untuk data yang harus selalu fresh, gunakan `no-store`.

```ts
async function getCurrentUser() {
  const response = await fetch("https://example.com/api/me", {
    cache: "no-store",
  });

  return response.json();
}
```

## Memoization Saat Render

Request `fetch` yang sama dapat dimemoisasi selama satu render pass di Server Component tree. Artinya, jika beberapa komponen memanggil request `GET` yang sama dengan opsi yang sama, Next.js dapat membagikan hasilnya selama render tersebut.

Memoization ini berbeda dari persistent cache. Memoization hanya hidup selama render, sedangkan cache bisa hidup lebih lama.

## Cache Components

Next.js 16 juga menyediakan model Cache Components melalui directive `"use cache"` ketika fitur `cacheComponents` diaktifkan.

```ts filename="next.config.ts"
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  cacheComponents: true,
};

export default nextConfig;
```

Setelah aktif, fungsi async bisa diberi cache.

```ts filename="app/lib/products.ts"
import { cacheLife } from "next/cache";

export async function getProducts() {
  "use cache";
  cacheLife("hours");

  const response = await fetch("https://example.com/api/products");
  return response.json();
}
```

## Kapan Perlu Cache?

Gunakan cache ketika:

- Data jarang berubah.
- Data sama untuk banyak user.
- Request cukup mahal.
- User tidak harus melihat perubahan secara instan.

Hindari cache ketika:

- Data sangat personal.
- Data harus selalu fresh.
- Data bergantung pada request user seperti cookie atau header.

## Ringkasan

Caching membantu performa, tetapi perlu dipakai dengan niat yang jelas. Pertanyaan utamanya bukan hanya "bisa dicache atau tidak", tetapi "berapa lama data ini aman dianggap benar".
