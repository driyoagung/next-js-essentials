---
title: Dynamic Data
description: Memahami data yang harus dibaca pada request time.
---

Dynamic data adalah data yang nilainya baru diketahui saat request terjadi. Contohnya cookie user, header request, session, query string, atau data yang harus selalu fresh.

## Contoh Dynamic Fetch

```tsx filename="app/dashboard/page.tsx"
async function getDashboardStats() {
  const response = await fetch("https://example.com/api/dashboard", {
    cache: "no-store",
  });

  return response.json();
}

export default async function DashboardPage() {
  const stats = await getDashboardStats();

  return <pre>{JSON.stringify(stats, null, 2)}</pre>;
}
```

`cache: "no-store"` menyatakan bahwa response tidak disimpan di cache framework dan perlu diambil ulang.

## Runtime API

Beberapa API hanya punya nilai saat request:

```tsx filename="app/profile/page.tsx"
import { cookies } from "next/headers";

export default async function ProfilePage() {
  const cookieStore = await cookies();
  const token = cookieStore.get("token")?.value;

  return <p>Token exists: {token ? "yes" : "no"}</p>;
}
```

Karena cookie bergantung pada request user, hasilnya tidak bisa dianggap sama untuk semua user.

## Search Params

Di Next.js 16, `searchParams` pada Page juga Promise.

```tsx filename="app/products/page.tsx"
export default async function ProductsPage({
  searchParams,
}: {
  searchParams: Promise<{ q?: string }>;
}) {
  const { q = "" } = await searchParams;

  return <p>Search keyword: {q}</p>;
}
```

## Hubungan dengan Suspense

Jika route memakai runtime data atau uncached async work, pisahkan area yang menunggu data dengan `<Suspense>` agar static shell masih bisa tampil lebih cepat.

```tsx filename="app/dashboard/page.tsx"
import { Suspense } from "react";

export default function DashboardPage() {
  return (
    <main>
      <h1>Dashboard</h1>
      <Suspense fallback={<p>Loading stats...</p>}>
        <DashboardStats />
      </Suspense>
    </main>
  );
}

async function DashboardStats() {
  const response = await fetch("https://example.com/api/dashboard", {
    cache: "no-store",
  });
  const stats = await response.json();

  return <pre>{JSON.stringify(stats, null, 2)}</pre>;
}
```

## Ringkasan

Dynamic data perlu diperlakukan berbeda dari data statis. Jika data bergantung pada request user atau harus selalu fresh, jangan cache sembarangan dan sediakan fallback UI yang jelas.
