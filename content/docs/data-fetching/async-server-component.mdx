<Callout type="info" title="Definisi singkat">
Async Server Component adalah Server Component yang memakai `async` dan `await` untuk mengambil data sebelum UI dirender.
</Callout>

Server Component dapat dibuat `async`, sehingga data bisa diambil saat render di server.

## 💻 Contoh Page Async

```tsx filename="app/posts/page.tsx"
type Post = {
  id: number;
  title: string;
};

async function getPosts(): Promise<Post[]> {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts");

  if (!response.ok) {
    throw new Error("Failed to fetch posts");
  }

  return response.json();
}

export default async function PostsPage() {
  const posts = await getPosts();

  return (
    <main>
      <h1>Posts</h1>
      <ul>
        {posts.slice(0, 5).map((post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </main>
  );
}
```

Dengan pola ini, browser menerima hasil render yang sudah berisi data awal.

## 🧩 Params pada Dynamic Route

Di Next.js 16, `params` adalah Promise. Jika mengambil data berdasarkan dynamic route, `params` perlu di-`await`.

```tsx filename="app/posts/[id]/page.tsx"
type Post = {
  id: number;
  title: string;
  body: string;
};

async function getPost(id: string): Promise<Post> {
  const response = await fetch(
    `https://jsonplaceholder.typicode.com/posts/${id}`,
  );

  if (!response.ok) {
    throw new Error("Failed to fetch post");
  }

  return response.json();
}

export default async function PostDetailPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const post = await getPost(id);

  return (
    <article>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}
```

## ⚡ Sequential vs Parallel

Jika dua request tidak saling bergantung, mulai keduanya dulu lalu tunggu bersama.

```tsx
const usersPromise = fetch("https://example.com/api/users");
const productsPromise = fetch("https://example.com/api/products");

const [usersResponse, productsResponse] = await Promise.all([
  usersPromise,
  productsPromise,
]);
```

Pola ini mencegah waterfall yang tidak perlu.

## 🧪 Studi Kasus: Dashboard dengan Dua Data

Dashboard sering membutuhkan beberapa data sekaligus, misalnya daftar employee dan daftar department. Jika keduanya tidak saling bergantung, jalankan paralel.

```tsx
export default async function DashboardPage() {
  const employeesPromise = getEmployees();
  const departmentsPromise = getDepartments();

  const [employees, departments] = await Promise.all([
    employeesPromise,
    departmentsPromise,
  ]);

  return <Dashboard employees={employees} departments={departments} />;
}
```

<Callout type="idea" title="Hindari waterfall">
Jika request B tidak membutuhkan hasil request A, jangan tunggu A selesai untuk memulai B.
</Callout>

## 📝 Latihan

Perbaiki pola berikut agar request berjalan paralel:

```tsx
const users = await getUsers();
const products = await getProducts();
```

## ✅ Ringkasan

- Server Component bisa `async`.
- Data bisa diambil langsung sebelum UI dikirim ke browser.
- `params` dan `searchParams` pada Next.js 16 perlu diakses sebagai Promise.
- Request yang tidak saling bergantung sebaiknya dijalankan paralel.
