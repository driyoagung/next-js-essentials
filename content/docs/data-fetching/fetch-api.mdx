---
title: Fetch API
description: Mengambil data menggunakan fetch di Next.js Server Component.
---

Next.js memakai Web `fetch()` API dan menambahkan perilaku khusus untuk server-side rendering, caching, dan revalidation.

Di App Router, kamu bisa memanggil `fetch()` langsung di Server Component.

## Contoh Dasar

```tsx filename="app/users/page.tsx"
type User = {
  id: number;
  name: string;
  email: string;
};

export default async function UsersPage() {
  const response = await fetch("https://jsonplaceholder.typicode.com/users");
  const users = (await response.json()) as User[];

  return (
    <main>
      <h1>Users</h1>
      <ul>
        {users.map((user) => (
          <li key={user.id}>
            {user.name} - {user.email}
          </li>
        ))}
      </ul>
    </main>
  );
}
```

Karena `UsersPage` memakai `await`, function page dibuat `async`.

## Cek Response

Jangan langsung menganggap request selalu berhasil. Cek `response.ok` sebelum memakai data.

```tsx filename="app/users/page.tsx"
type User = {
  id: number;
  name: string;
};

async function getUsers(): Promise<User[]> {
  const response = await fetch("https://jsonplaceholder.typicode.com/users");

  if (!response.ok) {
    throw new Error("Failed to fetch users");
  }

  return response.json();
}

export default async function UsersPage() {
  const users = await getUsers();

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

Error yang dilempar saat render dapat ditangani oleh `error.tsx` pada route segment yang sama atau parent terdekat.

## Opsi Cache pada Fetch

Next.js mendukung opsi cache pada server-side `fetch`.

```ts
await fetch("https://example.com/api/products", {
  cache: "force-cache",
});
```

```ts
await fetch("https://example.com/api/products", {
  cache: "no-store",
});
```

Gunakan `force-cache` ketika data aman disimpan di cache. Gunakan `no-store` ketika data harus selalu fresh pada setiap request.

## Revalidate dengan Fetch

Kamu juga bisa memberi umur cache dengan `next.revalidate`.

```ts
await fetch("https://example.com/api/products", {
  next: {
    revalidate: 60,
  },
});
```

Contoh di atas menyatakan data paling lama dianggap fresh selama 60 detik.

## Ringkasan

- `fetch()` bisa dipakai langsung di Server Component.
- Selalu cek `response.ok` untuk request yang bisa gagal.
- `cache: "force-cache"` menyimpan response.
- `cache: "no-store"` meminta data fresh.
- `next.revalidate` memberi interval refresh berbasis waktu.
