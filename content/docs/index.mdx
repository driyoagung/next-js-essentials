Dokumentasi ini disusun sebagai jalur belajar Next.js dari dasar sampai konsep essential yang sering dipakai saat membangun aplikasi web modern.

Materi ditulis bertahap untuk pembaca yang sudah mengenal dasar JavaScript atau React, lalu ingin memahami bagaimana Next.js mengatur routing, rendering, data, API, sampai kesiapan production.

## Alur Belajar

Setiap bab akan mengikuti pola yang konsisten:

```text
Konsep
Penjelasan
Contoh sederhana
Studi kasus
Implementasi
```

## Peta Materi

1. Pengenalan Next.js
2. Routing
3. Layout
4. Server Component dan Client Component
5. Data Fetching
6. Loading dan Error Handling
7. Route Handler / API
8. CRUD dengan studi kasus Employee Management
9. Form dan Server Actions
10. Database
11. Authentication
12. Production Essential

## Target Akhir

Setelah menyelesaikan seri ini, kamu diharapkan mampu membaca struktur project Next.js, membangun halaman dengan App Router, mengambil data, membuat API, mengelola form, membuat CRUD, menghubungkan database, menambahkan authentication, dan menyiapkan aplikasi untuk production.
