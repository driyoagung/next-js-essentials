description: Memahami boundary antara komponen server dan komponen client.
---

Bab ini membahas model rendering React yang dipakai Next.js App Router.

## Fokus Pembelajaran

- Apa itu Server Component
- Apa itu Client Component
- Kapan menggunakan Server Component
- Kapan menggunakan Client Component
- Directive `"use client"`
- State dan event pada Client Component

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menentukan komponen mana yang tetap di server dan komponen mana yang perlu berjalan di browser.
