Bab ini membahas cara Next.js membungkus halaman dengan layout yang dapat digunakan ulang.

Layout membantu kita menjaga struktur UI tetap konsisten. Navbar, sidebar, wrapper, provider, dan elemen global lain bisa diletakkan di layout agar tidak ditulis ulang di setiap page.

## Alur Bab Ini

1. Root layout
2. Nested layout
3. Shared layout dengan navbar dan sidebar

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menyusun UI bersama untuk beberapa halaman tanpa menyalin struktur yang sama berulang kali.
