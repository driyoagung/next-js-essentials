Bab ini membahas cara Next.js membungkus halaman dengan layout yang dapat digunakan ulang.

## Fokus Pembelajaran

- Root layout
- Nested layout
- Shared layout
- Navbar
- Sidebar
- Prop `children`

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menyusun UI bersama untuk beberapa halaman tanpa menyalin struktur yang sama berulang kali.
