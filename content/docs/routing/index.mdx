Bab ini membahas bagaimana URL dibentuk dari struktur folder di dalam direktori `app`.

## Fokus Pembelajaran

- Basic routing
- Nested route
- Dynamic route
- Catch-all route
- Navigasi dengan `Link`
- Navigasi programmatic dengan `useRouter`
- Membaca parameter dengan `useParams`
- Membaca query string dengan `useSearchParams`

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat membuat halaman statis, halaman dinamis, nested route, dan navigasi antar halaman dengan pola App Router.
