Bab ini membahas bagaimana URL dibentuk dari struktur folder di dalam direktori `app`.

Di App Router, route dibuat dari folder. File `page.tsx` membuat sebuah route bisa diakses oleh user, sedangkan file lain seperti `layout.tsx`, `loading.tsx`, dan `error.tsx` menambah perilaku di sekitar route tersebut.

## Alur Bab Ini

1. Basic routing
2. Nested route
3. Dynamic route dan catch-all route
4. Navigasi dengan `Link`, `useRouter`, `useParams`, dan `useSearchParams`

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat membuat halaman statis, halaman dinamis, nested route, dan navigasi antar halaman dengan pola App Router.
