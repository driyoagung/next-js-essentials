Bab ini menjadi pintu masuk sebelum masuk ke routing, layout, rendering, dan fitur framework lainnya.

Next.js bukan pengganti React. Next.js adalah framework yang memakai React sebagai fondasi UI, lalu menambahkan routing, rendering, data fetching, optimasi asset, dan kemampuan backend yang sering dibutuhkan aplikasi web modern.

## Kenapa Mulai dari Struktur?

Sebelum menulis fitur, kamu perlu tahu file mana yang membuat route, file mana yang membungkus tampilan, dan file mana yang hanya menjadi pendukung. Pemahaman ini membuat bab routing dan layout terasa jauh lebih natural.

## Alur Bab Ini

1. Memahami apa itu Next.js
2. Membandingkan Next.js dengan React + Vite
3. Membaca struktur project App Router

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menjelaskan mengapa Next.js dipakai, membaca struktur project awal, dan memahami file mana yang bertanggung jawab terhadap halaman serta layout aplikasi.
