## Fokus Pembelajaran

- Apa itu Next.js
- Perbedaan Next.js dengan React + Vite

- Struktur folder dasar

- Peran `page.tsx`
- Peran `layout.tsx`

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menjelaskan mengapa Next.js dipakai, membaca struktur project awal, dan memahami file mana yang bertanggung jawab terhadap halaman serta layout aplikasi.
