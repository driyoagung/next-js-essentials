description: Menangani form dengan Server Actions dan pending state.

Bab ini membahas cara mengirim data dari form ke server tanpa membuat endpoint API manual untuk setiap aksi.

## Fokus Pembelajaran

- Form handling
- Server Actions
- Directive `"use server"`
- Form action
- Pending state
- Validation
- `useActionState`

## Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat membuat form yang memanggil aksi server, menampilkan pending state, dan menangani validasi input.
