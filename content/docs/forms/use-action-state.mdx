---
title: useActionState
description: Mengembalikan state validasi dan pending dari Server Action ke form.
---

`useActionState` dipakai ketika Server Action perlu mengembalikan state ke UI, misalnya pesan validasi, error field, atau status sukses.

Hook ini menggantikan pola lama `useFormState`. Pada React 19, gunakan `useActionState`.

## Bentuk State

Mulai dengan type state yang sederhana.

```ts filename="app/signup/actions.ts"
export type SignupState = {
  message?: string;
  errors?: {
    email?: string;
    password?: string;
  };
};
```

## Action dengan State

Action yang dipakai oleh `useActionState` menerima state sebelumnya sebagai argumen pertama, lalu `FormData` sebagai argumen kedua.

```ts filename="app/signup/actions.ts"
"use server";

export async function signup(
  _state: SignupState,
  formData: FormData,
): Promise<SignupState> {
  const email = formData.get("email");
  const password = formData.get("password");

  const errors: SignupState["errors"] = {};

  if (typeof email !== "string" || !email.includes("@")) {
    errors.email = "Email is invalid";
  }

  if (typeof password !== "string" || password.length < 8) {
    errors.password = "Password must be at least 8 characters";
  }

  if (Object.keys(errors).length > 0) {
    return {
      errors,
      message: "Please fix the form",
    };
  }

  await createUser({
    email,
    password,
  });

  return {
    message: "Account created",
  };
}
```

## Client Form

Karena `useActionState` adalah hook, form component perlu menjadi Client Component.

```tsx filename="app/signup/signup-form.tsx"
"use client";

import { useActionState } from "react";
import { signup, type SignupState } from "./actions";

const initialState: SignupState = {};

export function SignupForm() {
  const [state, action, pending] = useActionState(
    signup,
    initialState,
  );

  return (
    <form action={action}>
      <label htmlFor="email">Email</label>
      <input id="email" name="email" type="email" />
      {state.errors?.email ? <p>{state.errors.email}</p> : null}

      <label htmlFor="password">Password</label>
      <input id="password" name="password" type="password" />
      {state.errors?.password ? <p>{state.errors.password}</p> : null}

      {state.message ? <p>{state.message}</p> : null}

      <button type="submit" disabled={pending}>
        {pending ? "Creating..." : "Create account"}
      </button>
    </form>
  );
}
```

## Kapan Pakai useActionState?

Gunakan `useActionState` ketika:

- Form perlu menampilkan validation error dari server.
- Form perlu menampilkan pesan sukses tanpa redirect.
- UI perlu membaca return value action.
- Pending state perlu langsung tersedia di component form.

Jika action selalu redirect setelah sukses dan error ditangani global, form sederhana dengan `useFormStatus` mungkin sudah cukup.

## Ringkasan

`useActionState` menghubungkan return value Server Action ke UI form. Ini cocok untuk validasi server yang perlu ditampilkan langsung di field.
