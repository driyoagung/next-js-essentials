![Diagram production readiness](/diagrams/production-readiness-flow.svg)

Bab ini menjadi penutup seri dengan fokus pada hal-hal yang perlu diperhatikan sebelum aplikasi dipakai di environment production.

Production bukan hanya menjalankan `npm run build`. Kamu perlu memastikan konfigurasi environment aman, metadata siap, image dan font optimal, strategi rendering jelas, error UI tersedia, dan deployment punya proses validasi.

Bab ini merangkum checklist praktis sebelum aplikasi Next.js dipakai user sungguhan.

## 🎯 Hasil yang Diharapkan

Setelah bab ini selesai, kamu dapat menyiapkan konfigurasi dasar production dan memahami keputusan penting sebelum deploy aplikasi Next.js.

## 🧠 Mental Model

```text
Kode selesai
Environment dikonfigurasi
Build dijalankan
Asset dioptimalkan
Error UI disiapkan
Security dicek
Deploy dilakukan
Monitoring berjalan
```

## 🧪 Studi Kasus Bab Production

Bayangkan aplikasi Employee Management siap dipakai internal perusahaan. Sebelum deploy, kamu perlu memastikan:

- `DATABASE_URL` production sudah benar.
- Auth secret berbeda dari local.
- Semua halaman penting punya metadata.
- Image dan font tidak menyebabkan layout shift.
- Route protected tetap mengecek session di server.
- Error UI tersedia untuk dashboard dan CRUD.
- Monitoring aktif setelah deploy.

## 📝 Latihan Pemanasan

Buat checklist production untuk aplikasi CRUD sederhana yang punya auth, database, image upload, dan dashboard admin.
